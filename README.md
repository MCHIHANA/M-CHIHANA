# Misheck Chihana — Personal Portfolio

A refined, lightweight, black-led developer portfolio engineered with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS**. Focused on visual clarity, concise content, smaller project previews, and direct contact.

---

## Architectural Principles & Visual Language

- **Black-Led Technical Theme**: Dominant near-black surfaces (`#080808`, `#101010`, `#151515`) with high-contrast text (`#F5F5F2`, `#A3A3A3`) and technical accents (Soft Lime `#B7F397` and Burgundy `#8F1D2C`).
- **Typography**: Space Grotesk (headings), Inter (body readability), and IBM Plex Mono (technical annotations, status codes, coordinates).
- **Engineering Graphics**: Subtle CSS hairline grid background, calibrated 144-node pixel matrix, and minimal measurement crosshairs.
- **Content Integrity**: Concise, authentic, 100% verified projects and technical tools.

## Local Development

To run the portfolio locally on Windows PowerShell:

```powershell
# Run the local Turbopack development server
npm.cmd run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

---

## Production Build & Verification

```powershell
# Type check with TypeScript compiler
npx.cmd tsc --noEmit

# Compile production bundle
npm.cmd run build

# Start production server locally
npm.cmd run start
```
